Transform core gallery block into a responsive and beautiful masonry grid with just a few clicks.

== Description ==

FlexiLayouts extends the WordPress block editor with powerful layout options and animations. Easily convert Gallery block into a responsive and stunning masonry grids without writing a single line of code.

= Key Features =

* **Masonry Grids**: Create beautiful masonry layouts in gallery block
* **Responsive Controls**: Fine-tune settings for different screen sizes ( coming soon )
* **Performance Optimized**: Built with modern JavaScript and CSS

= Source files =

[github](https://github.com/coderz-studio/flexilayouts)

= Supported Blocks =

* Core/Gallery

== Installation ==

1. Upload the `flexilayouts` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Edit Gallery block to access the new layout options

== Frequently Asked Questions ==

= How do I create a Masonry Gallery? =

1. Add Gallery Block
2. Open the block settings in the right sidebar
3. Navigate to the 'Layout' tab
4. Select 'masonry' from the layout options
5. Customize the masonry settings as needed

= Can I use this with my theme? =

Yes! FlexiLayouts is designed to work with any WordPress theme that supports the block editor.

= Is this plugin compatible with page builders? =

FlexiLayouts works with the default WordPress block editor. Compatibility with third-party page builders may vary.
